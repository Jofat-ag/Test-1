# StudyNote

A lightweight educational notebook web app.

## Features
- Dashboard with note statistics
- Create, edit, search, and delete notes
- Subject organization
- Responsive mobile/desktop UI
- LocalStorage persistence
- No external libraries or API keys

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Deployment
This repository is prepared as a static site. No deployment/hosting configuration has been activated yet.
